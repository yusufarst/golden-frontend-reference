# Inter (self-hosted)

- Family: Inter 4.x variable (axes: `wght` 100–900, `opsz` 14–32), upright + italic.
- Files: `InterVariable.woff2`, `InterVariable-Italic.woff2`.
- Source: official distribution by the author, https://rsms.me/inter/ (`/inter/font-files/InterVariable*.woff2?v=4.1`),
  project repository https://github.com/rsms/inter.
- Licence: SIL Open Font License 1.1 — full text in `LICENSE.txt` (copied from the official repository).
- Downloaded: 2026-10-06 for the MULTIPLECORP Golden Visual Reference Lab, with the owner's approval.

Usage in this lab: declared once in `assets/css/base.css` via `@font-face`; the UI uses the text cut
(`font-optical-sizing: none`, i.e. `opsz` 14) as established in `analysis/static-reference-analysis.md` §3.2.
